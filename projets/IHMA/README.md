# Projets d’Interaction Homme-Machine Avancée (IHMA)

Ce dossier rassemble trois projets réalisés dans le cadre de travaux en
Interaction Homme-Machine. Ils explorent différentes facettes de l’interaction
et de son évaluation : la visualisation interactive de données, les techniques
de pointage et la saisie sur clavier virtuel.

## Projets

### Visualisation interactive de villes françaises

[Consulter le README du projet](visualisation/README.md)

Une application de visualisation cartographique développée avec Processing.
Elle représente des données démographiques de villes françaises et permet
d’explorer la carte avec le zoom et le déplacement, de filtrer les villes par
population et de consulter les informations détaillées d’une ville.

**Technologies :** Processing (Java), données tabulées (`villes.tsv`).

### Expérimentation sur les techniques de curseur

[Consulter le README du projet](experience/README.md)

Un environnement d’expérimentation contrôlée pour comparer plusieurs
techniques de pointage : curseur classique, Bubble Cursor et Rope Cursor. Le
projet organise les essais et les cibles, puis collecte des mesures telles que
les temps de réalisation, les erreurs et les trajectoires.

**Technologies :** Python, interface graphique décrite dans le README du
projet.

### Clavier virtuel et évaluation de la saisie

[Consulter le README du projet](keyboard/README.md)

Un clavier virtuel destiné à explorer les dispositions de clavier, la saisie
de texte et les mécanismes de prédiction à partir d’un lexique français. Le
projet porte également sur l’évaluation de la performance de saisie, notamment
la vitesse et les erreurs.

**Technologies :** code et environnement d’exécution indiqués dans le README
du projet.
