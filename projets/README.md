# Dossier projets

Place ici chaque projet dans un sous-dossier dédié. Exemple :

projets/mon-projet-1/
  - README.md
  - src/
  - docs/
  - docker-compose.yml (si nécessaire)

Exemple de contenu pour le README d'un projet :

# Titre du projet

Courte description.

Technologies : Java, PostgreSQL, Docker

Installation :

```bash
# cloner
# entrer dans le dossier
# instructions d'installation
```

Lien(s) : demo, repository, issues
